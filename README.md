# VK — Фото на весь экран

[**Скачать установочный пакет 1.2.0**](https://github.com/Quake-Journey/VK-Photo-Fullscreen/releases/download/v1.2.0/VK-Photo-Fullscreen-1.2.0-RU.zip)
· [Все релизы](https://github.com/Quake-Journey/VK-Photo-Fullscreen/releases)
· [Инструкция на русском](docs/distribution/INSTALL_RU.txt)

Локальное расширение Chrome для просмотрщика фотографий VK.
Полный экран, переключение внутри текущего альбома, увеличение колёсиком,
перетаскивание и плавное сглаживание. Версия 1.2.0 поддерживает локальное
нейросетевое увеличение ×2 / ×3 / ×4 и автокоррекцию яркости. Работает в уже авторизованной вкладке.

## Обновление уже установленного расширения

В `chrome://extensions/` нажми кнопку обновления на карточке **VK — Фото на весь экран**,
затем обнови вкладку VK. Если Chrome запросит новые разрешения на домены фотографий VK,
подтверди их: они нужны для чтения снимка и обработки внутри расширения.
При обновлении замени файлы в той же папке `extension`, из которой расширение
было установлено. Не перемещай и не удаляй её: Chrome использует файлы прямо из неё.

## Установка

Для передачи пользователям готов пакет `dist/VK-Photo-Fullscreen-1.2.0-RU.zip`.
Внутри — папка `extension`, русская инструкция `НАЧНИ ЗДЕСЬ.txt` и текст для Telegram.
Пакет не содержит Node.js, тестов или локальных рабочих путей.
Повторная упаковка из корня проекта: `python tools/package-release.py`.
Редактируемые тексты находятся в `docs/distribution/`.

1. В Chrome открой `chrome://extensions/`.
2. Включи **Режим разработчика** справа вверху.
3. Нажми **Загрузить распакованное расширение**.
4. Выбери папку `extension` внутри распакованного пакета.
   Внутри выбранной папки должен лежать `manifest.json`.
5. Обнови уже открытую вкладку VK и открой фотографию в альбоме.
6. Справа вверху появится синяя кнопка **На весь экран**.

Chrome закрывать не нужно. Входить в VK заново тоже не нужно.
Если используешь ZIP, сначала распакуй его в постоянную папку, затем выбери
вложенную папку `extension`. После установки эту папку не удаляй.

## Управление

| Действие | Управление |
|---|---|
| Открыть полный экран | Синяя кнопка или Alt+Enter при открытой фотографии |
| Следующее / предыдущее фото | Стрелки справа и слева либо → / ← |
| Масштаб | Колесо мыши или кнопки − / + |
| Сдвиг увеличенной фотографии | Перетаскивание левой кнопкой мыши |
| Вписать фотографию целиком | «Вписать» или 0 |
| Исходный размер | «1:1» или 1 |
| Увеличить / вернуться к вписыванию | Двойной щелчок по фотографии |
| Сглаживание | «Плавно» или более мягкий режим «Мягче» |
| Улучшение | Галочка «Улучшать фото», включена по умолчанию |
| Множитель ИИ | Список ×2 / ×3 / ×4 справа от галочки, по умолчанию ×2 |
| Выйти | Esc или крестик справа вверху |

Фотография сохраняет пропорции и вписывается в экран, включая увеличение
маленьких снимков. Стрелки остаются доступны в полном экране.
После выхода остаётся открыта текущая фотография VK.
Если браузер отказал в полном экране, просмотр работает на всё окно;
кнопка ⛶ справа вверху позволяет повторить переход.

Расширение выбирает большую версию из доступного `srcset` или ссылки на оригинал,
если VK разместил её в просмотрщике. Адреса подписанных изображений не изменяются.
Используется плавная интерполяция браузера, а не растягивание квадратных пикселей.

## Улучшение фотографий

Галочка **«Улучшать фото» включена по умолчанию**. Пока идёт обработка, виден оригинал
и её ход; перелистывание, увеличение и выход остаются доступны.
Сними галочку, чтобы сразу сравнить с оригиналом при том же масштабе.
Повторное включение использует уже готовый результат текущего фото.
Рядом выбирается **×2, ×3 или ×4** — во столько раз увеличиваются ширина и высота
исходника. Смена множителя запускает обработку заново, но сохраняет масштаб и сдвиг
просмотра. Выбор действует и для следующих фотографий до перезагрузки вкладки.
×3 и ×4 требуют больше времени и памяти; большее разрешение не гарантирует больше
достоверных деталей в очень маленьком исходнике.

- Небольшие снимки увеличиваются локальными моделями **ESRGAN Slim 2×, 3× или 4×**
  через UpscalerJS и TensorFlow.js. Это нейросетевая обработка, а не только интерполяция.
- Затем адаптивная коррекция смягчает излишнюю яркость, поднимает слишком тёмные
  изображения и умеренно корректирует контраст. Исходный файл не меняется.
- Модель и её веса входят в расширение. Фотография обрабатывается на компьютере,
  без отправки в сторонние сервисы и без скачивания модели при просмотре.
- ИИ применяется к исходникам до 0,9 Мп с длинной стороной до 1400 пикселей.
  Результат ИИ ограничен 12 Мп, поэтому при ×4 исходник должен быть не больше 0,75 Мп.
  Более крупные снимки получают автокоррекцию без уменьшения исходного разрешения.
  Для снимков больше 12 Мп или файлов больше 20 МБ остаётся оригинал.
- Если WebGL или модель недоступны, остаётся автокоррекция, о чём сообщает статус.
  Если VK не разрешил прочитать файл, сохраняется обычный просмотр оригинала.
- При смене фотографии и выключении галочки обработка отменяется.
  После минуты без работы модель освобождает свои ресурсы.

Полностью белые участки без сохранившихся деталей восстановить достоверно нельзя.
Нейросеть может уточнять фактуру приблизительно; галочка позволяет сравнить результат.
Скорость зависит от размера фото и видеокарты; первый запуск загружает локальную модель.

## Доступ и совместимость

- Автоматически работает только на доменах `vk.ru` и `vk.com` и их поддоменах.
- Не запрашивает пароль, токен, разрешение `cookies` или доступ к истории.
- Читает выбранное фото с доменов VK и его CDN: `userapi.com`, `vkuserphoto.ru`,
  `vkuserphoto.com`, `vk-cdn.net`, `vkuser.net`, `vk.ru`, `vk.com`.
  Другие адреса и перенаправления обработчиком не принимаются.
- Не отправляет фотографии в сторонние сервисы и не собирает альбом целиком.
- Использует штатные стрелки VK; при неизвестных элементах пробует клавиши ← / →.
- Разметка VK может меняться. Текущая версия поддерживает классический просмотрщик
  `pv_photo`, несколько вариантов PhotoViewer/MediaViewer и диалоги с изображениями.

## Проверки версии 1.2.0

30.09.2026: Chrome 154.0.8037.58, отдельный временный профиль, headless.
Десять групп браузерных проверок: полный экран, фото малого размера, сглаживание,
масштаб и сдвиг, навигация без двойного шага, края альбома, Esc, динамический
просмотрщик, отказ Fullscreen API и более крупный источник изображения.

Отдельно проверена реальная установка manifest расширения в тестовый Chrome:
автоматическое внедрение на VK, работа при строгих CSP/Trusted Types,
полный экран и навигация, отсутствие внедрения на постороннем сайте.
Также проверены реальный запуск локальной модели в offscreen-документе расширения,
увеличение 192×128 → 384×256 / 576×384 / 768×512, включённая по умолчанию галочка, возврат к оригиналу
без изменения масштаба, повторное включение без загрузки фото и отмена при навигации.
Модель работает и при запрете `data:`-изображений политикой CSP страницы VK.
Проверены смена множителя при выключенной галочке, сохранение масштаба,
переключение между моделями и отмена устаревших результатов при быстром выборе ×2 → ×4 → ×3.
Отдельные проверки покрывают коррекцию светлых/тёмных снимков и ограничения адресов.
Тестовые окна не показывались; рабочий профиль и вкладки пользователя не трогались.

Проверки использовали локально подставленные страницы с разметкой VK.
Авторизованный живой альбом пользователя не был доступен автоматическим проверкам.
Скриншот пользователя изучен; окончательная проверка актуальной разметки — после
загрузки расширения в его обычный Chrome.

Для повторения тестов из корня проекта: `npm ci`, `npm run build`, затем `npm test`.
Для установки расширения Node.js и npm не нужны.

## Исходный код и сборка

```sh
git clone https://github.com/Quake-Journey/VK-Photo-Fullscreen.git
cd VK-Photo-Fullscreen
npm ci
npm run build
npm test
python tools/package-release.py
```

Для разработки нужны Node.js с npm, Python 3 и установленный Google Chrome.
Проверено на Node.js 24 и Python 3.14. Скрипт тестов использует стандартный путь
Chrome для Windows; для другой установки задай переменную окружения `CHROME_PATH`.
Готовый пользовательский ZIP появится в `dist/`.

| Каталог | Содержимое |
|---|---|
| `extension/` | Готовое расширение, модели и лицензии сторонних компонентов |
| `src/` | Исходники нейросетевого обработчика и тоновой коррекции |
| `tools/` | Сборка обработчика и упаковка установочного ZIP |
| `tests/` | Проверки интерфейса, реальной установки, моделей и коррекции |
| `docs/` | Русская документация, описание реализации и текст для Telegram |

Код TensorFlow.js и UpscalerJS собирается из зависимостей с закреплёнными версиями
в `package-lock.json`. Веса ESRGAN Slim входят и в репозиторий, и в установочный ZIP.
При просмотре фотографий скачивать модели отдельно не требуется.

Проблемы и предложения: [Issues](https://github.com/Quake-Journey/VK-Photo-Fullscreen/issues).
Для сообщения об ошибке достаточно версии Chrome и расширения, текста статуса
обработки и шагов воспроизведения; пароль и токены VK не нужны.
