# VK — Фото на весь экран · 1.2.0

Расширение Google Chrome для полноэкранного просмотра фотографий VK с локальным
нейросетевым улучшением.

## Скачать и установить

Скачай **VK-Photo-Fullscreen-1.2.0-RU.zip** из вложений к этому релизу.
Это готовый установочный пакет; архивы **Source code** предназначены для разработки.

1. Распакуй ZIP в постоянную папку.
2. Открой `chrome://extensions/` и включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение» и выбери вложенную папку **extension**,
   в которой находится `manifest.json`.
4. Обнови вкладку VK, открой фотографию и нажми **«На весь экран»**.

В архиве находятся русская инструкция **НАЧНИ ЗДЕСЬ.txt** и готовый текст для Telegram.
Документы также доступны отдельными вложениями **INSTALL_RU.txt** и **TELEGRAM_RU.txt**.
Папку `extension` после установки оставь на месте.

## Возможности

- Полный экран с сохранением пропорций и стрелками для переключения фото альбома.
- Увеличение колёсиком, перемещение фотографии мышью, вписывание и размер 1:1.
- Плавное сглаживание и дополнительный мягкий режим.
- Локальное нейросетевое увеличение небольших фотографий **×2 / ×3 / ×4**.
- Автокоррекция яркости и контраста.
- Галочка **«Улучшать фото»** включена по умолчанию; рядом выбирается множитель.
  Эти элементы находятся на нижней панели внутри полноэкранного просмотра.
- Мгновенное сравнение с оригиналом при снятии галочки.
- Переключение множителя сохраняет масштаб просмотра; перелистывание доступно
  во время обработки, устаревший результат не заменяет следующую фотографию.

Обработка выполняется на компьютере. Все три модели входят в пакет;
снимки не отправляются в сторонние сервисы, исходники на сайте не меняются.

## Совместимость и ограничения

Нужен Google Chrome 116 или новее. Установка проверена на Windows с Chrome 154.
Для ИИ используется WebGL; если он недоступен, остаётся автокоррекция.
×3 и ×4 требуют больше времени и памяти. Для крупных исходников применяется
только автокоррекция — подробные пределы указаны в инструкции.
Полностью потерянные из-за пересвета детали восстановить достоверно нельзя.

Пакет распространяется вне Chrome Web Store и устанавливается распакованным;
автоматического обновления из магазина нет.
При обновлении замени файлы в ранее установленной папке `extension`, нажми
значок обновления на карточке расширения и обнови вкладку VK.

Проверены полноэкранный просмотр, навигация, реальная установка расширения,
строгие CSP/Trusted Types, исполнение всех трёх моделей и отмена обработки.
Тесты выполнялись в отдельном профиле Chrome.
